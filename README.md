# Aetheria Chronicles - Admin Portal & Management System

ระบบส่วนหลังบ้าน (Admin Portal) สำหรับจัดการข้อมูลและบริหารระบบ **Aetheria Chronicles**

## 📌 คุณสมบัติหลัก (Features)

* **Dashboard Overview:** แสดงภาพรวมข้อมูล สถิติ และสถานะการทำงานของระบบแบบ Real-time
* **Data Management:** ระบบจัดการข้อมูลผู้ใช้งาน รายการ และเนื้อหาต่างๆ
* **Responsive Design:** รองรับการแสดงผลทุกขนาดหน้าจอ ทั้งคอมพิวเตอร์และอุปกรณ์เคลื่อนที่

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)

* **Frontend:** HTML5, CSS3, JavaScript
* **Version Control:** Git & GitHub
